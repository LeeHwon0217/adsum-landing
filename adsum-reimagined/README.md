# Adsum Reimagined

기존 랜딩과 앱 소스를 읽기 전용으로 참고해 새로 만든 독립 랜딩 페이지입니다.

## 실행

```bash
npm install
npm run dev
```

프로덕션 빌드:

```bash
npm run build
```

## 디자인 방향

- 생각난 말이 시간 토큰으로 바뀌어 캘린더에 착지하는 **키네틱 데스크톱 극장**
- 잉크 블랙, 전기빛 라임, 바이올렛, 피치의 제한된 팔레트
- 제품의 실제 흐름(말하기 → 코드 검증 → 로컬 저장)을 애니메이션으로 표현
- 실제 앱의 32×32 SVG 구조를 그대로 재구성한 입체 아숨 캐릭터
- 커서 시선 추적과 `idle / thinking / working / urgency` 상태 데모
- 사용자 수·후기·가격처럼 근거가 없는 주장은 추가하지 않음
- `prefers-reduced-motion` 및 키보드 포커스 지원

`design-reference/`에는 생성한 콘셉트와 데스크톱·모바일 브라우저 검증 캡처가 있습니다.
